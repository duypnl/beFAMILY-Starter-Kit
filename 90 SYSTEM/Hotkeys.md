# Hotkeys

## Bộ phím tắt beFAMILY

| Phím tắt | Lệnh | Khi dùng |
|---|---|---|
| `Ctrl + Alt + T` | Templater: Open insert template modal | Chèn template vào note đang mở |
| `Ctrl + Alt + N` | Templater: Create new note from template | Tạo note mới trực tiếp từ template |
| `Ctrl + Alt + D` | Daily notes: Open today's daily note | Mở hoặc tạo nhật ký hôm nay |
| `Ctrl + P` | Command Palette | Tìm mọi lệnh Obsidian |
| `Ctrl + N` | Create new note | Tạo note trống |

## Cách dùng note-template có menu Metadata

### Chèn vào note đang mở

1. Mở một note trống.
2. Nhấn `Ctrl + Alt + T`.
3. Chọn `note-template`.
4. Chọn lần lượt `type`, `domain` và `subtype`.

### Tạo note mới từ template

1. Nhấn `Ctrl + Alt + N`.
2. Chọn template cần dùng.
3. Đặt tên note nếu Templater yêu cầu.

## Lưu ý

`Ctrl + Alt + T` trước đây trỏ vào Core Templates. Binding cũ đã được gỡ để tránh chạy nhầm; từ nay phím này luôn mở Templater.
